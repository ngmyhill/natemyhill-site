# Dr Nate Myhill, orthopaedic surgeon

Website for Dr Nate Myhill's practice: https://drnatemyhill.com.au

Built with Next.js 16 (App Router), React 19, Tailwind CSS 4 and TypeScript, hosted on Vercel.

- Pushing to `main` deploys to production. Other branches get a private preview link.
- Start with `HANDOVER.md`: current state, accounts, DNS and how to make a change.
- AI assistants must follow `AGENTS.md` (Ahpra advertising rules, voice, accessibility, deploy rules).
- Run locally: `npm install`, then `npm run dev`. Check with `npm run build` before merging.
- Contact details and locations live in `src/lib/data.ts`.
